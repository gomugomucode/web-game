# web-game

Otter Run: 3D River Racing Game built with Next.js 16, React 19, Three.js, @react-three/fiber, @react-three/drei, and Tailwind CSS.

## Features (Milestone 1)
- 3D Otter arcade movement on water plane (WASD / Arrow Keys)
- Water drift / lateral grip physics
- Dash mechanic with speed burst and cooldown (Space)
- Live movement tuning with Leva
- High-performance HUD with speed, heading, and dash cooldown indicator

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
